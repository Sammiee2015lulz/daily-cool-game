# Daily Cool Game 🎮

A new fun browser game every day!

## Today's Game: **Neon Dodger** 🚀

Dodge the red meteors and catch the golden stars!

- Use **Arrow Keys** or **A/D** to move
- On mobile: **Swipe** left/right
- Catch stars for +10 points
- Survive as long as you can!

### Play it live
Enable GitHub Pages on this repo and open the site, or just download and open `index.html`.

### How to enable GitHub Pages
1. Go to Settings → Pages
2. Source: Deploy from a branch → `main` / `/ (root)`
3. Save
